## p012 · 书内第 3 页 · Introduction（导论）

**Introduction**（导论）

本教材讲的是**如何用数学模型与方法去分析计算机科学中出现的问题**。proof 在这项工作里处于中心位置，因为三位作者与多数数学家共享一个信念：proof 是真正理解一件事的必要条件。proof 在计算机科学里的作用还在不断扩大；它们被用来担保软件与硬件将**始终**正确行事——这是任何数量的测试（testing）都做不到的事。

简单说，proof 是一种确立真理的方法。与美类似，「真理」有时取决于观者的眼睛，因此在不同的领域里，什么算作 proof 各不相同，这并不值得奇怪。举例来说：在司法系统里，法律上的真相（legal truth）由陪审团依据庭审中允许呈递的证据裁定；在商业世界里，权威的真相（authoritative truth）由某个受信任的人或机构指定，或者干脆由你的老板说了算；在物理学、生物学这类领域，科学上的真相（scientific truth）由 experiment（实验）确认<sup>1</sup>；在统计学里，或然的真相（probable truth）通过对样本数据的统计分析确立。

哲学意义上的证明则涉及细致的阐述与说服，通常建立在一连串细小而可信的论证之上。最好的例子从「Cogito ergo sum」开始，这句拉丁文译作「我思故我在」（I think, therefore I am）。这句话出自 17 世纪数学家兼哲学家 René Descartes 一篇随笔的开头，是世上最著名的引语之一：上网搜一下，你会被结果淹没。

从「你正在思考自己的存在」推出「你存在」，是个挺酷、听起来相当有说服力的想法。然而只要再多走几行……

> <sup>1</sup> 其实，只有科学上的**虚假**能被 experiment 演示出来——当 experiment 的表现不如预测时。但无论多少 experiment 都无法确认下一次 experiment 不会失败。正是因为这个原因，科学家极少谈 truth，宁可谈 theory：一个能准确预测试过的、以及预期中未来 experiment 的 theory。

<span style="color:#1e8449;">**[译注]** 本页把 proof 定义为「确立 truth 的方法」，然后把司法、商业、物理、统计、哲学各自的「真」并排列出。这段对比不是修辞装饰，它承担着第 1 章之后所有形式化工作的动机：**只有数学的 proof 能做到对全部情形成立**，其余领域的「真」都带条件（证据是否允许呈递、样本是否随机、experiment 是否可重复）。抽掉这一条，硬件与软件验证就只能退回 testing，而 testing 只能否证、不能证实（作者在本页注脚 1 已经点明这一层）。量级上这不是空的担忧：一个 32 位整数输入的取值空间是 $2^{32}\approx 4.3\times 10^{9}$，一个 64 位乘加单元的输入组合超过 $1.8\times 10^{19}$，穷举在任何时钟频率下都不成立；1994 年 Pentium FDIV 的缺陷正是查找表里 **5 个表项**缺失造成的，靠用户上报才被发现，而厂商的测试流程当时认为已经通过。反过来，若把「proof 覆盖全部输入」这层意思删掉，第 5 章 §5.4 的 state machines（状态机）不变量论证也会一起失效——invariant（不变量）之所以强，就是因为它约束的是**所有可达状态**，而不是抽样命中的状态。落点：本页正文第二段 + 注脚 1；Prop 1.1.3 的反例见 p.5；Intel 除法 bug 见 p.8 原文「the notorious Intel division bug in the 1990's」；state machines 见 §5.4 p.130。</span>

## p013 · 书内第 4 页（页眉 §0.1 References；正文为导论续文 + 证明的定义）

（本页顶部 running head 已排成 `0.1. References`，但版面主体仍是导论段落的续文，直到页中才出现 §0.1 的文献列表。）

……沿着这类论证再走几行，Descartes 就得出结论：存在一位无限仁慈的上帝。无论你是否相信这样一位上帝，你大概都会同意：任何关于「上帝无限仁慈」的极短「证明」都必然是牵强的。所以即便在极高明的手里，这条路也不可靠。

数学有它自己关于「proof」的特定概念。

**Definition.** 对某个 proposition 的**数学证明（mathematical proof）**，是从一组基础 axiom 出发、以该 proposition 为终点的一串 logical deduction。

这个定义里有三个关键想法被着重标出：**proposition、logical deduction、axiom**。第 1 章考察这三个想法，以及若干组织证明的基本方式。第 2 章引入良序原理（well ordering principle, WOP），一种基本的证明方法；稍后，第 5 章引入与它密切相关的证明方法——归纳法（induction）。

如果你打算证明一个 proposition，那你最好先精确理解这个 proposition 到底是什么意思。为了避免日常语言里的歧义与含混定义，数学家极其精确地使用语言，并且常常用逻辑公式来表达 proposition；这些是第 3 章的主题。

前三章假定读者已经熟悉少数几个数学概念，例如集合（set）与函数（function）。第 4 章与第 7 章更仔细地考察这类数学数据类型（mathematical data types），特别是考察关于无限集（infinite set）的性质与证明方法。第 6 章接着考察递归定义的数据类型（recursive data type）。

## p014 · 书内第 5 页 · 第 1 章 What is a Proof?（何谓证明）· §1.1 Propositions

### 第 1 章 · 1 What is a Proof?（何谓证明）

## 1.1 Propositions（命题）

**Definition.** 一个 **proposition（命题）** 是一个要么为真、要么为假的陈述（communication）。

例如，下面两句都是 proposition：第一句为真，第二句为假。

**Proposition 1.1.1.** $2 + 3 = 5$.

**Proposition 1.1.2.** $1 + 1 = 3$.

「非真即假」听起来限制不大，但它确实排除了这样一些语句：「Wherefore art thou Romeo?」（罗密欧，你为什么是罗密欧？）和「Give me an A!」（给我个 A！）。它同时也排除了真值随情境变化的语句，例如「现在五点了」，或者「股市明天会上涨」。

可惜的是，判断一个 proposition 是真还是假，并不总是容易的事：

**Proposition 1.1.3.** 对每个非负整数 $n$，$n^2 + n + 41$ 的值都是素数（prime）。

（prime 是大于 1、且不被任何大于 1 的其他整数整除的整数。例如 2、3、5、7、11 就是前五个 prime。）让我们做一点数值实验来检验这个 proposition。令

```math
p(n) ::= n^2 + n + 41. \qquad (1.1)
```

我们从 $p(0) = 41$ 出发，它是 prime；接着

```math
p(1) = 43,\quad p(2) = 47,\quad p(3) = 53,\ \dots,\ p(20) = 461
```

也各自是 prime。嗯，看起来像个可信的断言。事实上我们可以一直验到 $n = 39$，确认 $p(39) = 1601$ 是 prime。

但 $p(40) = 40^2 + 40 + 41 = 41 \cdot 41$，它不是 prime。所以「该表达式对所有非负整数都取 prime 值」并不成立。事实上，不难证明：**没有任何整系数多项式**能把所有非负数都映到 prime 上。

> <sup>1</sup> 符号 $::=$ 的意思是「按定义相等」（equal by definition）。直接写「$=$」而不写 $::=$ 永远是可以的，但提醒读者某个等式是按定义成立的，有时是有帮助的。

<span style="color:#1e8449;">**[译注]** 这 40 个连续样本是全章最有价值的一个反例装置，值在于它的**规模是刻意挑小的**：$n=0..39$ 全部取 prime 值，$p(39)=1601$ 也是 prime，检查到这里几乎任何人都会倾向于相信它；而 $p(40)=41\cdot 41 = 1681$ 一次就把命题推翻。它要建立的不是「$41$ 这个数特殊」，而是**有限个正例对全称命题（$\forall n\in\mathbb{N}$）没有证明力**，无论样本多大。同型的坑在后文还有两处：原文 p.7 提到 Fermat 大定理曾被验到 $n\le 4\times 10^{6}$ 仍不能算证明；$n^2+n+41$ 的素数性上界是 $n\le 39$，而 Fermat 数 $F_5 = 2^{32}+1 = 641\cdot 6700417$ 在 $n=4$ 就崩了。抽掉这条，第 2 章的 WOP 与第 5 章的 induction 就都变成没有动机的技巧：它们唯一的功能，正是把「对每个 $n$ 都成立」从**有限抽查**（永不给结论）换成**两条固定义务**（base case + 归纳步），义务数从 $O(\infty)$ 降到 $2$。落点：Proposition 1.1.3 与式 (1.1) 本页；原书指向的 Problem 1.17 在习题区；对照 §2.2 模板 p.28 与 §5.1 p.115。</span>

顺带一提，像这种「关于所有数」或「关于某类所有对象」的 proposition 太常见了，以至于专门有一套记号。用这套记号，Proposition 1.1.3 会写成

```math
\forall n \in \mathbb{N}.\ p(n)\ \text{is prime}. \qquad (1.2)
```

这里符号 $\forall$ 读作「对所有」（for all）。符号 $\mathbb{N}$ 代表非负整数集合：$0, 1, 2, 3, \dots$（完整列表请问你的老师）。符号 $\in$ 读作「是……的成员」「属于」，或者干脆读作「在……之中」。$\mathbb{N}$ 后面那个句点只是短语之间的分隔符。

下面是两个更极端的例子：

**Proposition 1.1.4.**〔Euler 猜想（Euler's Conjecture）〕方程

```math
a^4 + b^4 + c^4 = d^4
```

在 $a, b, c, d$ 均为正整数时无解。

Euler（读作「oiler」）在 1769 年提出这个猜想。但这个 proposition 在 **218 年**后，被 Mass Ave 街上（沿麻省大道）一所文理学院的 Noam Elkies 证明为假。他找到的解是 $a = 95800,\ b = 217519,\ c = 414560,\ d = 422481$。

用逻辑记号，Euler 猜想可以写成

```math
\forall a \in \mathbb{Z}^{+}\, \forall b \in \mathbb{Z}^{+}\, \forall c \in \mathbb{Z}^{+}\, \forall d \in \mathbb{Z}^{+}:\ a^4 + b^4 + c^4 \neq d^4.
```

这里 $\mathbb{Z}^{+}$ 是正整数集合的记号。这样一串 $\forall$ 通常会被缩写，以便阅读：

```math
\forall a, b, c, d \in \mathbb{Z}^{+}:\ a^4 + b^4 + c^4 \neq d^4.
```

**Proposition 1.1.5.** $313\left(x^3 + y^3\right) = z^3$ 在 $x, y, z \in \mathbb{Z}^{+}$ 时无解。

这个 proposition 也是假的，但它最小的反例有**超过 1000 位**（decimal digits）！

值得再提几个著名的 proposition，它们的证明在被找到之前，人们追寻了几个世纪：

**Proposition 1.1.6**（Four Color Theorem，四色定理）. 每张地图都能用 4 种颜色着色，使得相邻<sup>2</sup>的两个区域颜色不同。

> <sup>2</sup> 只有共享一段正长度边界的两块区域才算相邻（adjacent）。如果两块区域的边界只在几个点处接触，它们不算相邻。

这个定理曾有若干份错误的证明被公开发表，其中一份在 19 世纪后期**站了 10 年**才被人发现其中的错误。一份费力的证明最终由数学家 Appel 与 Haken 在 1976 年给出，他们用了一个复杂的计算机程序来对可四着色的地图分类。程序留下几千张地图未被分类，由 Haken 及其助手手工核对——助手之一是他 15 岁的女儿。

**Proposition 1.1.7**（Fermat's Last Theorem，费马大定理）. 不存在正整数 $x$、$y$、$z$，使得对某个整数 $n > 2$ 有

```math
x^n + y^n = z^n.
```

Fermat 在 1630 年前后读到的一本书里声称自己有此 proposition 的证明，只是页边空白不够，写不下。此后多年间，该定理被验证到对所有 $n \le 4{,}000{,}000$ 成立，但我们已经看到，这未必能让人相信它对**所有** $n$ 成立。毕竟 Fermat 大定理与 Euler 那个已被推翻的猜想之间有着明显的相似性。最终，在 1994 年，英国数学家 Andrew Wiles 给出了证明——此前他在自家阁楼里秘密而孤立地工作了七年。他的证明装不进任何页边空白。<sup>4</sup>

最后，再提一个陈述简单、真值至今未知的 proposition。

**Proposition 1.1.8**（Goldbach's Conjecture，哥德巴赫猜想）. 每个大于 2 的偶数都是两个 prime 之和。

Goldbach 猜想可追溯到 1742 年。已知它对所有不超过 $10^{18}$ 的数成立，但直到今天，没有人知道它是真还是假。

对计算机科学家来说，最需要证明的东西之一是程序与系统的**正确性（correctness）**——一个程序或系统是否做了它该做的事。程序出 bug 是出了名的，而试图找到证明程序正确性之路的研究者与工程师群体正在扩大。在 CPU 芯片这一情形上，这些努力已经足够成功，以至于它们现在被主要芯片厂商常规性地用于证明芯片正确、并避免 1990 年代那个臭名昭著的 Intel 除法 bug 一类的错误。

发展用于验证程序与系统的数学方法，仍是一个活跃的研究领域。我们会在第 5 章演示其中一些方法。

## 1.2 Predicates（谓词）

predicate 可以理解为一种 proposition，它的真值依赖于一个或多个变量的取值。所以「$n$ 是一个 perfect square」描述的是一个 predicate，因为在知道变量 $n$ 取什么值之前，你无法说它是真还是假。一旦知道了，比如知道 $n$ 等于 4，这个 predicate 就变成真 proposition「4 是一个 perfect square」。记住，没有任何要求说这个 proposition 必须为真：如果 $n$ 的值是 5，你得到的就是假 proposition「5 是一个 perfect square」。

与其他 proposition 一样，predicate 常用一个字母来命名。此外还使用一种类似函数的记号，来表示一个被赋予具体变量值的 predicate。例如，我们可以用名字 $P$ 表示上面那个 predicate：

```math
P(n) \mathrel{::=} \text{"}n\text{ is a perfect square"}
```

并把上面的话重述为：$P(4)$ 为真，$P(5)$ 为假。这个 predicate 记号与普通函数记号相似到令人困惑的程度。若 $P$ 是一个 predicate，那么 $P(n)$ 依 $n$ 的取值或真或假；而若 $p$ 是普通函数，比如 $n^2+1$，那么 $p(n)$ 是一个数值。不要把这两者搞混！

## 1.3 The Axiomatic Method（公理方法）

在数学中确立真理的标准程序是 Euclid 发明的，他是公元前 300 年左右在埃及亚历山大城工作的一位数学家。他的想法是从五条关于几何的假设（assumption）出发，这些假设基于直接经验，看起来不可否认。（例如「每一对点之间都有一段直线段」。）

## p018 · 书内第 9 页（§1.3 续 · §1.4 Our Axioms）

……像这样被直接接受为真的 proposition，称为 axiom（公理）。

从这些 axiom 出发，Euclid 通过给出「proof」确立了许多附加 proposition 的真。一份 proof 是从 axiom 与先前已证命题出发的一串 logical deduction，它以所讨论的那个 proposition 收尾。你大概在中学几何课上写过很多 proof，本书里你还会看到更多。

对一个已被证明的 proposition，有几个常见的称呼；不同的称呼暗示该 proposition 在更大的工作体系中所扮演的角色。

- 重要的真 proposition 称为 theorem（定理）。
- lemma（引理）是为证明后续 proposition 作准备用的 proposition。
- corollary（推论）是从某个 theorem 出发、只需几步 logical deduction 就能得到的 proposition。

这些定义并不精确。事实上，有时一个好 lemma 最终远比当初用它来证明的那个 theorem 更重要。

Euclid 这套「axiom + proof」的路子，现在被称为公理方法（axiomatic method），至今仍是数学的基础。事实上，只要少数几条 axiom——称为 Zermelo-Fraenkel with Choice axioms（ZFC）——再加上少数几条 logical deduction 规则，看来就足以推出几乎全部数学。我们会在第 7 章考察它们。

## 1.4 Our Axioms（我们采用的公理）

ZFC 公理在研究、并为数学的基础作辩护时很重要，但就实用目的而言，它们太原始了。在 ZFC 里证明 theorem，有点像用 byte code 而不是用一门完整的编程语言写程序——按某一种估算，ZFC 中「$2+2=4$」的一条形式证明需要**两万步以上**。所以我们的出发点不是 ZFC，而是把一个巨大的 axiom 集合当作地基：我们将接受中学数学里的一切熟悉事实。

这会让我们起步很快，但你有时会觉得这套不精确的 axiom 规定令人不安。例如，在证明进行到一半时，你可能开始犯嘀咕：「这个小事实我必须证吗，还是可以直接把它当 axiom？」这里其实没有绝对答案，因为什么算合理的假设、什么必须证明，取决于情境与听众。一条好的通则很简单：**把你假设了什么摊在明面上**。

## p019 · 书内第 10 页（§1.4.1 Logical Deductions）

### 1.4.1 Logical Deductions（逻辑演绎）

logical deduction，或称 inference rule（推理规则），被用来借助已证命题去证明新的 proposition。

一条基本的 inference rule 是 modus ponens（肯定前件式）。这条规则说的是：一个对 $P$ 的 proof，加上一个对「$P$ IMPLIES $Q$」的 proof，构成一个对 $Q$ 的 proof。

inference rule 有时用一种古怪的记号书写。例如 modus ponens 写作：

**Rule.**

```math
\frac{P,\quad P \Rightarrow Q}{Q}
```

当横线**上方**的语句（称为 antecedents，前件）已被证明时，我们就可以认为横线**下方**的语句（称为 conclusion 或 consequent，结论）也已被证明。

对 inference rule 的一项关键要求是它必须 **sound（可靠）**：任何使所有 antecedent 为真的、对字母 $P, Q, \dots$ 的真值指派（assignment of truth values），也必须使 consequent 为真。于是，只要我们从真的 axiom 出发、并且只使用 sound 的 inference rule，我们所证明的一切也都会是真的。

还有许多其他自然且 sound 的 inference rule，例如：

**Rule.**

```math
\frac{P \Rightarrow Q,\quad Q \Rightarrow R}{P \Rightarrow R}
```

**Rule.**

```math
\frac{(\neg P) \Rightarrow (\neg Q)}{Q \Rightarrow P}
```

另一方面，

**Non-Rule.**

```math
\frac{(\neg P) \Rightarrow (\neg Q)}{P \Rightarrow Q}
```

并不 sound：若把 $P$ 指派为 T、$Q$ 指派为 F，则 antecedent 为真而 consequent 为假。

与 axiom 的情形一样，我们不会对合法 inference rule 的集合过分形式化。proof 中的每一步都应当清楚且「合逻辑」；特别是，你应当说明每个新结论是由哪些先前已证的事实推出来的。

<span style="color:#1e8449;">**[译注]** 本页的 Non-Rule 是整个第一部分里最容易被「跳过」的一格，但它是两个方向的混淆点的**唯一判据**：合取（conjunction）方向与否定（negation）方向不对称。把四条真值指派代进 Non-Rule 的 antecedent $(\neg P)\Rightarrow(\neg Q)$ 与 consequent $P \Rightarrow Q$，$4$ 种指派中只有 $P=\mathrm{T}, Q=\mathrm{F}$ 这一种使前件真、后件假——恰好是 $2^2$ 中唯一的反例，所以这条规则看着「只差一点」，实际不 sound。可反驳的失效对象很具体：$(P\Rightarrow Q) \equiv (\neg Q \Rightarrow \neg P)$（上面第三条 Rule 就是这个等价），但 $(\neg P\Rightarrow\neg Q)$ 只是 converse（逆命题），与原命题不等价。抽掉「sound」这个判据，代码里的条件重写就会出错：把 `if (!p) ... if (!q)` 的可满足性约束按 Non-Rule 化成 `p ⇒ q`，约束集从原公式的 1 个模型变成 2 个模型（$P=\mathrm{F}$ 的两种指派被错误地放进来），SAT 求解器会给出原公式不满足的赋值。这也解释了 §1.6 p.13 为什么把「证明 iff」拆成两个 implication：方向信息不写清，两个方向都可能被偷换。落点：本页 Non-Rule 与上方三条 Rule；§1.6 p.13；§3.3 Equivalence and Validity p.48；§3.5 SAT p.55。</span>

## p020 · 书内第 11 页（§1.4.2 Patterns of Proof · §1.5 Proving an Implication 开头）

### 1.4.2 Patterns of Proof（证明的套路）

原则上，一份 proof 可以是任何一串从 axiom 与已证语句出发、以所论 proposition 收尾的 logical deduction。这种构造上的自由，起初可能显得铺天盖地：你究竟怎么**开始**一份 proof？

好消息是：许多 proof 都遵循少数几个标准模板之一。每个 proof 自然有它自己的细节，但这些模板至少提供了一个可以填写的骨架。我们会走一遍其中几个标准套路，点出基本想法与常见陷阱，并给出例子。这些模板有许多能拼在一起：某一个给你顶层骨架，另一个帮你在下一层细节上补全。后文我们还会给你看其他更精密的证明技术。

下面这些配方有时非常具体，会明确告诉你纸上该写下哪些字。你当然可以完全按自己的方式说；我们只是提供一套你可以照着说的话，好让你不至于完全无话可说。

## 1.5 Proving an Implication（如何证明一个蕴涵）

形如「If $P$, then $Q$」的 proposition 称为 **implication（蕴涵）**。这种 implication 常被改写成「$P$ IMPLIES $Q$」。

下面是几个例子：

- （Quadratic Formula，求根公式）若 $ax^2 + bx + c = 0$ 且 $a \neq 0$，则

```math
x = \left(-b \pm \sqrt{b^2 - 4ac}\right) / 2a.
```

- （Goldbach's Conjecture 1.1.8 的改写）若 $n$ 是大于 2 的偶整数，则 $n$ 是两个 prime 之和。
- 若 $0 \le x \le 2$，则 $-x^3 + 4x + 1 > 0$。

证明一个 implication 有几套标准方法。

### 1.5.1 Method #1（方法一）

为了证明 $P$ IMPLIES $Q$：

1. 写下「Assume $P$.」（假设 $P$。）
2. 证明 $Q$ 在逻辑上随之成立。

<span style="color:#1e8449;">**[译注]** 本页三个例子都被写成「If $P$ then $Q$」的形状，但真正决定证明义务的是 $P$ 的取值域，而三例的取值域并不相同：求根公式里 $a\neq 0$ 是前提的一部分，去掉它，$x$ 的分母就是 $0$，$a=b=0,\ c=1$ 时前件为假、整条 implication 因此为**真**（vacuously true，空真），可是解集是空的——「真」并不等于「有用」。这正是 §1.5.1 第一步要求写「Assume $P$」而不要求「检查 $P$ 是否为真」的原因：proof 只对 $P$ 为真的情形负责。抽掉 vacuous truth 这一层约定，带全称量词的 implication $\forall x\,(P(x)\Rightarrow Q(x))$ 在 $P$ 无解时就没有真值可言，第 3 章 §3.6 的 predicate formula 与第 11 章 §11.5 二分图匹配里「若不存在这样的顶点则条件自动满足」的论证会一起失效。构造上一个可检验的对比：把常数项改成不满足条件的式子，例如 $-x^3+4x-3 > 0$ 在 $x=0$ 处得 $-3$，前提 $0\le x\le 2$ 为真而结论为假，这一条才是有内容的假命题。落点：本页三个 bullet；§1.5.1 Method #1；对照 §1.1 的 Prop 1.1.3（同一个 $n$ 的前提写作 $n\in\mathbb{N}$）。</span>

## p021 · 书内第 12 页（§1.5 续：Theorem 1.5.1 的 scratchwork 与完整证明）

页眉 `"mcs" — 2015/5/18 — 1:43 — page 12 — #20`；running head 为 `Chapter 1 What is a Proof?`。

**Example**（例）

**Theorem 1.5.1.** *If $0 \le x \le 2$, then $-x^3 + 4x + 1 \gt  0$.*
（定理 1.5.1：若 $0 \le x \le 2$，则 $-x^3 + 4x + 1 \gt  0$。）

在写出这个 theorem 的 proof 之前，我们得先做一些 scratchwork（草稿推演），弄清楚它究竟为什么成立。

这个 inequality 在 $x=0$ 处当然成立：此时左边等于 $1$，而 $1 \gt  0$。随着 $x$ 增大，$4x$ 这一项（它是正的）起初看起来在绝对值上压过 $-x^3$（它是负的）。例如 $x=1$ 时，$4x = 4$，而 $-x^3$ 只有 $-1$。事实上，看上去要等到 $x \gt  2$，$-x^3$ 才开始占上风。于是看起来在 $0$ 到 $2$ 之间的所有 $x$ 上，$-x^3 + 4x$ 这一部分都应当是 nonnegative（非负）的，而这将蕴涵 $-x^3 + 4x + 1$ 为正。

到此为止还算顺利。但那些「看起来」「似乎」的说法，仍然必须全部替换成扎实的、合乎逻辑的论证。对于要害部分 $-x^3 + 4x$，只要把它 factoring（因式分解），我们就能更好地把握，而这并不太难：

```math
-x^3 + 4x = x(2-x)(2+x)
```

啊哈！当 $x$ 在 $0$ 与 $2$ 之间时，右边每一项都是 nonnegative；而非负项之积同样 nonnegative。现在把这一大堆零散观察整理成一个干净的 proof。

*Proof.* 假设 $0 \le x \le 2$。于是 $x$、$2-x$、$2+x$ 全都 nonnegative。因此这些项之积也 nonnegative。给这个乘积加上 $1$，得到的就是正数，所以：

```math
x(2-x)(2+x) + 1 \gt  0
```

把左边乘开即证明

```math
-x^3 + 4x + 1 \gt  0
```

正如所声称的那样。$\blacksquare$

<span style="color:#1e8449;">**[译注]** 这一步是全节唯一的技术动作：把「判断整条多项式的符号」换成「判断三个因子的符号」。它所依赖的代数事实只有一条——$a \ge 0$ 且 $b \ge 0$ 蕴涵 $ab \ge 0$（$\mathbb{R}$ 的序与乘法相容）。失效对象写清楚：抽掉这个因式分解，你就必须直接分析 $f(x) = -x^3+4x+1$ 的符号；在 $[0,2]$ 上 $f'(x) = -3x^2+4 = 0$ 给出 $x = 2/\sqrt{3} \approx 1.1547$，此处 $f \approx 4.079$，而端点 $x=0$ 处 $f = 1$，故命题仍为真，但证明手段从「一次乘法保号」升级成「求导 + 解二次方程 + 比较一个端点」，多出两次数值判断。这就是原书肯为它单独表演一次的原因。落点：本页因式分解式与 $x(2-x)(2+x)+1\gt 0$ 这一行；§1.5.1 的 Method #1 骨架；同一「代数变形不能逆向使用」的坑见 `p022` 的 Problem 1.3(c)。量的方向也值得记一笔：因式分解把「$3$ 个符号判断」压成「$1$ 次「非负乘非负仍非负」的引用」，而求导路线的成本是「$1$ 次求导 + $1$ 次解二次方程 + $2$ 次数值比较」。</span>

这里有几点适用于所有 proof：

- 在你试图理清一个 proof 的逻辑步骤时，常常需要做一些 scratchwork。你的 scratchwork 可以要多乱有多乱——充满死胡同、奇怪的图、脏话，随便什么。但要把它与最终的 proof 分开，后者应当清晰而简洁。

- proof 通常以 "Proof" 这个词开头，以某种界定符（delimiter）结尾，例如 $\square$ 或 "QED"。这些约定的唯一用途，是让人看清 proof 从哪里开始、到哪里结束。

## p022 · 书内第 13 页（§1.5.2 Method #2 逆否 · Theorem 1.5.2 · §1.6 开头）

页眉 `page 13 — #21`；running head 为 `1.6. Proving an "If and Only If"`。

### 1.5.2 Method #2 - Prove the Contrapositive（方法二：证明逆否命题）

一个 implication（"$P$ IMPLIES $Q$"）在逻辑上等价于它的 contrapositive（逆否命题）

```math
\text{NOT}(Q) \ \text{IMPLIES}\ \text{NOT}(P).
```

证明其中一个与证明另一个等价；而证明逆否有时比证明原陈述更容易。若确实如此，就可以照下面这样做：

1. 写下 "We prove the contrapositive:"，然后陈述逆否命题。
2. 按 Method #1 的流程继续。

**Example**（例）

**Theorem 1.5.2.** *If $r$ is irrational, then $\sqrt{r}$ is also irrational.*
（定理 1.5.2：若 $r$ 是无理数，则 $\sqrt{r}$ 也是无理数。）

一个数是 rational（有理数），当它等于两个整数之商——也就是说，当它等于 $m/n$，其中 $m$、$n$ 是某两个整数。若它不是 rational，就称为 irrational（无理数）。于是我们必须证明：若 $r$ 不是两个整数之比，则 $\sqrt{r}$ 也不是两个整数之比。这绕得相当厉害！改用 contrapositive，我们就能把两个 not 一并消掉，把证明简化。

<span style="color:#1e8449;">**[译注]** 这条 theorem 的陈述里藏着一个未写出的前提：$r \ge 0$。原书写 "If $r$ is irrational, then $\sqrt r$ is also irrational"，但按实数域上的主值平方根，$\sqrt{r}$ 只在 $r \ge 0$ 时有定义。抽掉这个前提会怎样：取 $r = -1$，前件「$-1$ 是无理数」为假（$-1$ 是有理数），整条 implication 因此是 vacuous true（空真），后件「$\sqrt{-1}$ 是无理数」根本没有真值可言——命题不是假，而是 ill-formed（不适定）。这正是逆否写法在这里格外合适的原因：逆否形式 "if $\sqrt r$ is rational, then $r$ is rational" 只对 $\sqrt r$ 存在的那种 $r$ 说话，把定义域的约束自动收进了前件。方向感也清楚：原命题要处理 $2$ 个 not，逆否把它降到 $0$ 个，正文因此只剩两步代数。落点：本页 Theorem 1.5.2 与其 Proof；§1.8 的 Theorem 1.8.1（同一套逆否/矛盾手法用在 $\sqrt2$ 上）；Problem 1.12（把 $\sqrt2$ 推广到 $\sqrt3$）。另有一处值得留意：若把 $r$ 取在 $r \ge 0$ 之外又强行代入，$\sqrt r$ 在 $\mathbb{R}$ 内无意义，整条改写立刻失效——这与 `p030` 的 Problem 1.2（$\sqrt{(-1)(-1)} = \sqrt{-1}\sqrt{-1}$）属同一类「公式越权使用」。</span>

*Proof.* 我们证明逆否命题：若 $\sqrt{r}$ 是 rational，则 $r$ 是 rational。假设 $\sqrt{r}$ 是 rational。于是存在整数 $m$ 与 $n$，使得：

```math
\sqrt{r} = \frac{m}{n}
```

两边平方，得到：

```math
r = \frac{m^2}{n^2}
```

既然 $m^2$ 与 $n^2$ 都是整数，$r$ 也就是 rational。$\blacksquare$

### 1.6.1 Method #1: Prove Each Statement Implies the Other（方法一：分别证明两个方向）

陈述 "$P$ IFF $Q$" 等价于两个陈述 "$P$ IMPLIES $Q$" 与 "$Q$ IMPLIES $P$"。所以你可以通过证明两个 implication 来证明一个 "iff"：

1. 写下 "We prove $P$ implies $Q$ and vice-versa."
2. 写下 "First, we show $P$ implies $Q$."，用 §1.5 中的某个方法完成。
3. 写下 "Now, we show $Q$ implies $P$."，同样用 §1.5 中的某个方法完成。

### 1.6.2 Method #2: Construct a Chain of Iffs（方法二：构造一条 iff 链）

要证明 $P$ 为真 iff $Q$ 为真：

1. 写下 "We construct a chain of if-and-only-if implications."
2. 证明 $P$ 等价于第二个陈述，第二个陈述等价于第三个陈述，如此下去，直到抵达 $Q$。

这个方法有时比前一个需要更多巧思，但结果可以是一个简短而优雅的 proof。

**Example**（例）

一列取值 $x_1, x_2, \ldots, x_n$ 的 standard deviation（标准差）定义为：

```math
\sqrt{\frac{(x_1-\mu)^2 + (x_2-\mu)^2 + \cdots + (x_n-\mu)^2}{n}}
```

其中 $\mu$ 是这些取值的 average（平均值），或称 mean（均值）：

```math
\mu ::= \frac{x_1 + x_2 + \cdots + x_n}{n}
```

**Theorem 1.6.1.** *The standard deviation of a sequence of values $x_1, \ldots, x_n$ is zero iff all the values are equal to the mean.*
（定理 1.6.1：一列取值 $x_1, \ldots, x_n$ 的 standard deviation 为零，当且仅当所有取值都等于 mean。）

例如，考试成绩的 standard deviation 为零，当且仅当每个人都恰好考了班级平均分。

*Proof.* 我们构造一条 "iff" implication 链，从「standard deviation 为零」这一陈述出发：

```math
\sqrt{\frac{(x_1-\mu)^2 + (x_2-\mu)^2 + \cdots + (x_n-\mu)^2}{n}} = 0
```

### 1.7 Proof by Cases（分情况证明）

把一个复杂的 proof 拆成若干 case、逐个分别证明，是一种常见而有用的证明策略。这里有一个有趣的例子。

我们约定：任给两个人，他们要么见过，要么没见过。若一个群体中每一对人都见过，我们称这个群体为一个 club（俱乐部）；若一个群体中每一对人都没见过，我们称它为一群 strangers（陌生人）。

**Theorem.** *Every collection of 6 people includes a club of 3 people or a group of 3 strangers.*
（定理：任意 6 个人的集合中，都包含一个 3 人的 club，或一个 3 人的 strangers。）

*Proof.* 本 proof 用 case analysis（分情况分析）$^5$。令 $x$ 记六人中的一人。有两种 case：

1. 除 $x$ 之外的其余 5 人中，至少 3 人见过 $x$。
2. 那 5 人中，至少 3 人没见过 $x$。

现在我们必须确认，这两种 case 至少有一种必然成立$^6$，而这很容易：我们已把这 5 个人分成两组——与 $x$ 握过手的，与没与 $x$ 握过手的，所以必有一组至少占了半数的人。

**Case 1：** 设至少 3 人确实见过 $x$。此 case 又分成两个 subcase：

> $^5$ 一开始就说明你的思路，有助于给读者定向。
> $^6$ case analysis 论证的一部分，就是说明你已经覆盖了所有 case。这一点常常显而易见，因为两个 case 形如「$P$」与「not $P$」。然而上面的情形并没有说得这么简单。

<span style="color:#1e8449;">**[译注]** 这一段是整个 case analysis 的承重点，也是全页唯一不能省的一步：作者必须证明两个 case 覆盖了全部可能，否则 proof 是残缺的。覆盖性靠的是一条计数事实——$5$ 个人按「是否见过 $x$」二分，两组人数之和为 $5$，故必有一组 $\ge \lceil 5/2 \rceil = 3$。这同一个论证对 $6$ 这个数字是紧的：把定理中的 $6$ 换成 $5$，结论立即失效。可验证的反例——把 $5$ 个人摆在五边形的五个顶点上，只让相邻两人见过面（图论语言：$5$-cycle $C_5$ 的边染色），此时既找不到 $3$ 人两两见过（$C_5$ 没有三角形），也找不到 $3$ 人两两没见过（$C_5$ 的补图仍是 $C_5$，同样没有三角形）。也就是说 $R(3,3) = 6$，而 $5$ 是它的严格下界。失效模式很具体：glossing over 覆盖性时，$n=5$ 的反例就藏在两个 case 的缝里而你不会发现。落点：本页 footnote 6 明确要求 "show you've covered all the cases"；本页 Case 1.1/1.2 与 `p025` 的 Case 2.1/2.2 构成两层划分；同一「计数覆盖性」手法见第 5 章 §5.4 的状态机终止性论证。</span>

### 1.8 Proof by Contradiction（反证法）

在 proof by contradiction（反证法）——也叫 indirect proof（间接证明）——中，你证明的是：若某个 proposition 为假，那么某个假事实就会为真。既然假事实按定义不可能为真，该 proposition 就必然为真。

proof by contradiction 永远是一条可行路线。不过正如这个名字所暗示的，indirect proof 可能稍显绕；因此在 direct proof（直接证明）可用时，通常更可取。

**Method**（方法）：要用 contradiction 证明一个 proposition $P$：

1. 写下 "We use proof by contradiction."
2. 写下 "Suppose $P$ is false."
3. 推出某个已知为假的东西（一个 logical contradiction，逻辑矛盾）。
4. 写下 "This is a contradiction. Therefore, $P$ must be true."

## p026 · 书内第 17 页（Theorem 1.8.1 $\sqrt2$ 无理 · §1.9 何为好证明）

页眉 `page 17 — #25`；running head 为 `1.9. Good Proofs in Practice`。

**Example**（例）

我们用 contradiction 来证明 $\sqrt{2}$ 是 irrational。记住：一个数是 rational，当且仅当它等于两个整数之比——例如 $3.5 = 7/2$，而 $0.1111\ldots = 1/9$，都是 rational 数。

**Theorem 1.8.1.** *$\sqrt{2}$ is irrational.*
（定理 1.8.1：$\sqrt{2}$ 是无理数。）

*Proof.* 我们用 proof by contradiction。假设该断言为假，即 $\sqrt{2}$ 是 rational。那么我们可以把 $\sqrt{2}$ 写成一个最简分数 $n/d$。

两边平方得 $2 = n^2/d^2$，于是 $2d^2 = n^2$。这意味着 $n$ 是 $2$ 的倍数（见 Problems 1.10 与 1.11）。因此 $n^2$ 必是 $4$ 的倍数。但既然 $2d^2 = n^2$，我们便知 $2d^2$ 是 $4$ 的倍数，于是 $d^2$ 是 $2$ 的倍数。这意味着 $d$ 是 $2$ 的倍数。

于是分子与分母有公因子 $2$，这与 $n/d$ 已是最简分数相矛盾。故 $\sqrt{2}$ 必为 irrational。$\blacksquare$

### 1.9 Good Proofs in Practice（实践中的好证明）

proof 的目的之一，是把一条断言的真理性确立到绝对确定；而那些长度或复杂度极大的、可被机械检验的 proof，能够做到这一点。但只有人类可理解的 proof，才能帮助某人真正理解这门学科。数学家们普遍认为，重要的数学结果在其 proof 被理解之前，无法被完整地理解。这就是 proof 成为课程大纲重要组成部分的原因。

一个 proof 若要可理解、有帮助，光有逻辑正确还不够：好的 proof 还必须清晰。正确与清晰通常相伴随——写得好的 proof 更可能是正确的 proof，因为错误更难藏身。

在实践中，proof 这个概念是一个 moving target（移动靶）。专业研究期刊上的 proof，除少数掌握其中全部术语与先验结果的专家外，一般人是看不懂的。反过来说，像 6.042 这样入门课程头几周的 proof，在职业数学家看来会被视为冗长乏味到令人厌烦。事实上，我们在本学期稍后所接受的好 proof，与 6.042 头两周所认为的好 proof 并不相同。但即便如此，我们仍能给出一些写好好 proof 的一般建议：

**State your game plan.**（交代你的总体思路。）好的 proof 开头会解释大致的推理路线，例如 "We use case analysis" 或 "We argue by contradiction"。

## p027 · 书内第 18 页（§1.9 续：写好 proof 的七条建议）

页眉 `page 18 — #26`；running head 为 `Chapter 1 What is a Proof?`。

**Keep a linear flow.**（保持线性流程。）有时 proof 被写成数学拼贴画，把彼此独立的推理碎片四处撒开。这不好。论证的各个步骤应当以一个可理解的次序彼此衔接。

**A proof is an essay, not a calculation.**（proof 是文章，不是计算。）许多学生起初写 proof 就像在算积分：结果是一长串没有解释的表达式，读起来非常吃力。这很差。好的 proof 通常看起来像一篇夹了些方程的文章。请使用完整的句子。

**Avoid excessive symbolism.**（避免过度符号化。）你的读者大概很会读文字，但对读那些晦涩的数学符号就远没那么娴熟。凡是能用文字的地方，就合理地用文字。

**Revise and simplify.**（修改并简化。）你的读者会为此感激你。

**Introduce notation thoughtfully.**（审慎地引入记号。）有时引入一个变量、设计一套特殊记号，或定义一个新术语，能极大简化论证。但要节制地这么做，因为你在要求读者记住所有这些新东西。而且别忘了真正去定义新变量、新术语、新记号的含义——不要上手就用！

**Structure long proofs.**（组织长的 proof。）长程序通常被拆成层级化的小过程。长 proof 大体同理。当你的 proof 需要一些易于陈述、却不易证明的事实时，最好把这些事实抽出来作为 preliminary lemmas（预备引理）。另外，如果你在反复重复本质上相同的论证，试着把这个论证收进一个一般性的 lemma，之后反复引用它。

**Be wary of the "obvious."**（警惕「显然」。）当 proof 中需要用到熟悉的、或确实显而易见的事实，把它标注为如此而不加证明是可以的。但请记住：对你而言显而易见的东西，对你的读者未必如此——而且通常确实不是。

> 尤其不要用 "clearly" 或 "obviously" 这类短语，企图把你自己都难以证明的东西硬塞给读者接受。同样，每当你在别人的 proof 里看到这类短语，就该警觉起来。

**Finish.**（收尾。）在 proof 的某个时刻，你已经把所需的关键事实全部确立完毕。此时要抵制「就此打住、让读者自己去得出那个『显然』结论」的诱惑。相反，请你自己把一切串起来，并解释为什么最初的断言随之成立。

**(c)** *Bogus Claim:* If $a$ and $b$ are two equal real numbers, then $a = 0$.

*Bogus proof.*

```math
\begin{aligned}
a &= b \\
a^2 &= ab \\
a^2 - b^2 &= ab - b^2 \\
(a-b)(a+b) &= (a-b)b \\

a &= 0.
\end{aligned}
```

<span style="color:#1e8449;">**[译注]** (c) 的假证明只有一处是错的，而且错在第四行到第五行之间：从 $(a-b)(a+b) = (a-b)b$「约掉」$(a-b)$ 得到 $a+b=b$。前提是 $a=b$，因此 $a-b=0$，这一步实际做的是除以 $0$。为什么它一定错：等式 $0\cdot x = 0\cdot y$ 对任意实数 $x,y$ 都成立，所以从 $0\cdot(a+b) = 0\cdot b$ 反推 $a+b=b$，等于承认 $\mathbb{R}$ 有乘法消去律而把 $0$ 当作例外——$\mathbb{R}$ 是域，$0$ 没有乘法逆元，消去律的前提恰恰是除数 $\ne 0$。可检验的具体数字：取 $a=b=1$，第四行两边都是 $0$，第五行左边 $2$、右边 $1$，差值为 $1$，而这差值信息在乘法里已被 $0$ 抹平。失效模式值得记住：这类错误在符号推演中不留任何痕迹（不像算错数字能被验算抓住），只能靠「每次除法先问除数是否为零」这一条检查项拦截。落点：本页 Problem 1.3(c)；`p028` 上 §1.9 对 bogus proof 的三分法（circular reasoning / leaping / left to the reader）；`p030` 的 Problem 1.2 是同一类「非法运算」的另一个实例（$\sqrt{ab}=\sqrt a\sqrt b$ 越权使用）。</span>

## 2 The Well Ordering Principle（良序原理）

> **Every *nonempty* set of *nonnegative integers* has a *smallest* element.**
> （每个**非空**的**非负整数**集合都有一个**最小**元素。）

这个陈述被称为 The Well Ordering Principle（良序原理）。你信它吗？看起来挺显然的，对吧？但请注意它的条件有多紧：它要求集合 nonempty——对空集它不成立，因为空集根本没有最小元素，它压根没有元素。而且它要求集合是 nonnegative integers——对负整数集不成立，对一些非负有理数集也不成立，例如正有理数集。所以，Well Ordering Principle 抓住了非负整数某种特殊的东西。

虽说 Well Ordering Principle 看起来显而易见，但一时之间很难看出它有什么用。而事实上，它提供了离散数学中最重要的证明规则之一。本章我们将用几个简单例子来展示这个证明方法的威力。

### 2.4 Well Ordered Sets（良序集）

一个数的集合是 well ordered（良序的），当它的每个非空子集都有最小元素。Well Ordering Principle 说的当然是：非负整数集是 well ordered 的；但其他许多集合也是，例如每个有限集，又如形如 $r\mathbb{N}$ 的集合——其元素是 $rn$ 这种数，其中 $r$ 是正实数、$n \in \mathbb{N}$。

在计算机科学里，well ordering 常作为证明「计算不会永远跑下去」的方法出现。思路是：给计算的相继各步指派一个值，使得每一步的值都在变小。若这些值全都取自一个 well ordered set，则该计算不可能永远跑下去——因为若它真永远跑下去，指派给相继各步的值就会构成一个没有最小元素的子集。你将在 §5.4 看到这项技巧的若干应用实例，用来证明各种状态机终将终止。

注意：一个集合可以有最小元素，却不是 well ordered。非负有理数集就是一个例子：它有最小元素零，但它也含有不含最小元素的非空子集——例如正有理数集。

下面这个 theorem 是对 Well Ordering Principle 的一个小小推广。

**Theorem 2.4.1.** *For any nonnegative integer, $n$, the set of integers greater than or equal to $-n$ is well ordered.*
（定理 2.4.1：对任意非负整数 $n$，大于等于 $-n$ 的整数所构成的集合是良序的。）

这个 theorem 和 Well Ordering Principle 一样显然，把它当作又一条 axiom 接受也无伤。但反复引入 axiom 迟早令人不安；而当一条潜在的 axiom 其实可以被证明时，注意到这一点是值得的。我们可以用 Well Ordering Principle 轻松证明 Theorem 2.4.1：

*Proof.* 令 $S$ 为任意非空、且元素都 $\ge -n$ 的整数集合。现在把 $n$ 加到 $S$ 的每个元素上；称这个新集合为 $S+n$。于是 $S+n$ 是非负整数的一个 nonempty 集合，故由 Well Ordering Principle，它有一个最小元素 $m$。但此时容易看出 $m-n$ 就是 $S$ 的最小元素。$\blacksquare$

well ordering 的定义指出：良序集的每个子集都是良序的，而这就给出 Theorem 2.4.1 两个便利而直接的 corollary（推论）：

### 2.4 Well Ordered Sets（良序集）（续）

**Definition 2.4.2.** *A lower bound (respectively, upper bound) for a set, $S$, of real numbers is a number, $b$, such that $b \le s$ (respectively, $b \ge s$) for every $s \in S$.*
（定义 2.4.2：实数集 $S$ 的 lower bound（下界）是这样一数 $b$：对每个 $s \in S$ 都有 $b \le s$；upper bound（上界）则要求对每个 $s \in S$ 都有 $b \ge s$。）

注意：集合 $S$ 的下界或上界**不要求**本身属于 $S$。

**Corollary 2.4.3.** *Any set of integers with a lower bound is well ordered.*
（推论 2.4.3：任何有下界的整数集都是良序的。）

*Proof.* 一个以 $b \in \mathbb{R}$ 为下界的整数集，同样会以整数 $n = \lfloor b \rfloor$ 为下界——这里 $\lfloor b \rfloor$ 称为 $b$ 的 floor（下取整），做法是把 $b$ 向下舍入到最近的整数。于是由 Theorem 2.4.1 可知该集合是良序的。$\blacksquare$

**Corollary 2.4.4.** *Any nonempty set of integers with an upper bound has a maximum element.*
（推论 2.4.4：任何有上界的非空整数集都有最大元素。）

*Proof.* 设整数集 $S$ 有上界 $b \in \mathbb{R}$。现在把 $S$ 的每个元素乘以 $-1$，称这个新元素集合为 $-S$。当然，$-b$ 就是 $-S$ 的下界。于是由 Corollary 2.4.3，$-S$ 有最小元素 $-m$。但此时容易看出 $m$ 就是 $S$ 的最大元素。$\blacksquare$

<span style="color:#1e8449;">**[译注]** 「有下界」这句在这里必须被抠开一层：**Theorem 2.4.1 只承诺「下界是整数」的情形，Corollary 2.4.3 才把下界放宽到实数**，缺口全靠一句 $n = \lfloor b \rfloor$ 补上。它成立的理由是 $\lfloor b \rfloor \le b \le s$，故 $\lfloor b \rfloor$ 仍是下界，而且它落在了 Theorem 2.4.1 的处理范围内（$-n$ 取 $n = -\lfloor b \rfloor$）。

**消失测试**：抽掉 floor 这一步，就无法把「$\mathbb{R}$ 中的下界 $b$」喂给「整数下界 $-n$」的定理；Theorem 2.4.1 只剩「下界恰好是整数」这一个特例，而这类集合在实际论证里很少出现。

**能一眼算完的最小反例**：取 $S = \{n \in \mathbb{Z} \mid n \ge \sqrt{2}\}$。这里 $b = \sqrt{2} \approx 1.4142$ 是下界却不是整数，$S = \{2, 3, 4, \dots\}$，最小值 $2 = \lceil \sqrt{2} \rceil$；若硬把 $b$ 截成 $1$，$1 \notin S$ 但这不影响它是下界——**下界不必在集合里**（定义 2.4.2 的注就是指这一句），这正是该证明里最容易读漏的一环。

**落点**：Theorem 2.4.1（上一册 p040）、§2.4.1、Problem 2.15(a)(b) 都在考同一个边界；实数侧的 floor/ceiling 见任何微积分/实分析教材第一章。</span>

#### 2.4.1 A Different Well Ordered Set (Optional)（另一个良序集·选读）

良序数集的另一个例子，是可以写成 $n/(n+1)$ 这种形式的分数所构成的集合 $\mathbb{F}$：

```math
\frac{0}{1},\ \frac{1}{2},\ \frac{2}{3},\ \frac{3}{4},\ \dots,\ \frac{n}{n+1},\ \dots.
```

$\mathbb{F}$ 的任意非空子集的最小元素，就是把它写成 $n/(n+1)$ 之后分子最小的那一个。

现在我们再加一点料，造出一个很不一样的良序集：把非负整数加到 $\mathbb{F}$ 里的数上。也就是说，取出所有形如 $n + f$ 的数，其中 $n$ 是非负整数、$f$ 是 $\mathbb{F}$ 里的数。你猜到了——把这个数集叫作 $\mathbb{N} + \mathbb{F}$。要在 $\mathbb{N} + \mathbb{F}$ 的任意非空子集里找出最小数，有一个简单的配方，这也说明了它为什么是良序的：

**Lemma 2.4.5.** *$\mathbb{N} + \mathbb{F}$ is well ordered.*
（引理 2.4.5：$\mathbb{N} + \mathbb{F}$ 是良序的。）

*Proof.* 给定 $\mathbb{N} + \mathbb{F}$ 的任意非空子集 $S$，考察所有那些使「对某个 $f \in \mathbb{F}$ 有 $n + f \in S$」成立的非负整数 $n$。这些 $n$ 构成一个非空的非负整数集，故由 WOP 存在最小者，记为 $n_S$。

按 $n_S$ 的定义，存在某个 $f \in \mathbb{F}$ 使 $n_S + f$ 属于 $S$。于是「使 $n_S + f \in S$ 成立的那些分数 $f$」构成 $\mathbb{F}$ 的一个非空子集；而 $\mathbb{F}$ 是良序的，所以这个非空子集含有最小元素，记为 $f_S$。此时容易验证 $n_S + f_S$ 就是 $S$ 的最小元素（Problem 2.14）。$\blacksquare$

<span style="color:#1e8449;">**[译注]** 这条证明真正在做的事是：**把一维的比较换成字典序（先比整数部分 $n$，再比分数部分 $f$），并保证每一层都还落在良序集里**。$\mathbb{F}$ 良序（分子最小者胜）＋ $\mathbb{N}$ 良序，两个良序接成一层「先 $n$ 后 $f$」的序，仍然良序；这套手艺后来在序数、以及程序终止性的多重度量（multiset/matrix 上的 well-founded order）里反复出现。

**消失测试**：把 $\mathbb{F}$ 换成全体非负有理数 $\mathbb{Q}_{\ge 0}$，$\min$ 立刻失踪——$\{q \in \mathbb{Q} \mid q \gt 0\}$ 没有最小元，于是 $n_S + f_S$ 不再存在，Lemma 2.4.5 整体塌掉，只剩「$n_S$ 存在」这一半。

**能直接算的最小反例**：$\mathbb{N} + \mathbb{Q}_{\ge 0}$ 中取 $S = \{0 + 1/k \mid k \ge 1\}$。它的整数部分恒为 $n = 0$，$n_S = 0$ 有了；但分数部分是 $\{1, 1/2, 1/3, \dots\}$，最小元只可能是 $\inf = 0 \notin S$。两集合的差别就落在这一点上：$\mathbb{F}$ 里没有「收敛到该元素之外」的无穷下降链。

**落点**：Lemma 2.4.5 与 Problem 2.14、Problem 2.15(e)(f)、Problem 2.17（良序 iff 无无穷下降链）构成一组；下一册 §5.4 的 state machine 终止性用的是同一套技巧。</span>

> † 原文作 "with no common factor prime factor"，"factor prime factor" 叠词，按上下文应为 "common prime factor"。

*Bogus proof.* 反设存在正有理数 $q$，使 $q$ 不能写成最简形式。令 $C$ 为这些「不能写成最简形式」的有理数之集。于是 $q \in C$，$C$ 非空。因此必存在最小的有理数 $q_0 \in C$。既然 $q_0/2 \lt q_0$，那么 $q_0/2$ 一定能写成最简形式，即

```math
\frac{q_0}{2} = \frac{m}{n}
```

其中 $m, n$ 为正整数且无公共素因子（原书编号 (2.4)）。现在考虑两种情形：

**Case 1**：[$n$ 为奇数]。则 $2m$ 与 $n$ 也没有公共素因子，因此

```math
q_0 = 2 \cdot \left(\frac{m}{n}\right) = \frac{2m}{n}
```

把 $q_0$ 写成了最简形式，矛盾。

**Case 2**：[$n$ 为偶数]。$m$ 与 $n/2$ 的任何公共素因子也会是 $m$ 与 $n$ 的公共素因子。因此 $m$ 与 $n/2$ 没有公共素因子，于是

```math
q_0 = \frac{m}{n/2}
```

把 $q_0$ 写成了最简形式，矛盾。

<span style="color:#1e8449;">**[译注]** 这份假证明的病灶只有一句：**「因此必存在最小的有理数 $q_0 \in C$」——而 $\mathbb{Q}^+$ 不是良序集，这一步把 WOP 从 $\mathbb{N}$ 非法搬到了 $\mathbb{Q}$。** 两块砖之后的 Case 1 / Case 2 都是干净的算术，唯一没有出处的是「最小者存在」。

**消失测试**：若能用这份证明，就能反过来「证明」$\sqrt{2}$ 是有理数——把同样的模板套上去：反设 $\sqrt2 = p/q$ 最简，则 $2 = p^2/q^2$ 给出 $p$ 偶、$q$ 偶，矛盾，于是「最简形式不存在」⇒ $\sqrt2$ 无理（碰巧结论正确，但推理只是运气）。真正被 WOP 支撑的那份证明（§2.1）取的是**分母最小**的正整数，而不是「最小的有理数」。

**能直接算的最小反例**：$C$ 若取 $\{1/n \mid n \ge 1\}$ 这类集合就根本没有最小元——$1 \gt 1/2 \gt 1/3 \gt \cdots$；只要取 $q_0 = 1/k$，总有更小的 $1/(k+1)$。再具体一点：让「非最简」的唯一来源是分母，$q_0 = 1/3$ 没问题，但 $q_0 = 2/6$ 的最简形式是 $1/3$，而 $1/3$ 也非最简就无从谈起——可见虚假的不是算术，是「最小者」这一环。

## 第 3 章 Logical Formulas（逻辑公式）

人们居然能应付 English 里所有这些歧义，这真是件了不起的事。下面这些句子就说明了问题：

- "You may have cake, or you may have ice cream."（你可以吃蛋糕，或者你可以吃冰淇淋。）
- "If pigs can fly, then you can understand the Chebyshev bound."（如果猪会飞，那么你能看懂 Chebyshev 界。）
- "If you can solve any problem we come up with, then you get an A for the course."（如果你能解出我们提出的任何问题，那么这门课你拿 A。）
- "Every American has a dream."（每个美国人都有一个梦想。）

这些句子**精确地**是什么意思？你可以既吃蛋糕又吃冰淇淋，还是只能选一样甜点？猪不会飞，那么第二句关于你是否看懂 Chebyshev 界，到底说了什么没有？如果你能解出我们提出的**某些**问题，这门课你能拿 A 吗？而如果你一个问题都解不出来，是否意味着你拿不到 A？最后，末句是否意味着所有美国人有同一个梦想——比如拥有一栋房子——还是不同美国人可以有不同梦想，比如 Eric 梦想写出一个杀手级软件，Tom 梦想当网球冠军，Albert 梦想能唱歌？

在日常交谈中，一点不确定性是可以容忍的。但当我们必须把想法精确地表述出来时——数学与编程里正是如此——日常语言固有的歧义就成了真正的问题。如果我们连陈述究竟在说什么都不确定，就别指望作出精确的论证。所以在进入数学之前，我们得先研究「如何谈论数学」这个问题。

为了绕开 English 的歧义，数学家设计了一门专门用来谈论逻辑关系的语言。这门语言大体上仍然使用 "or"、"implies"、"for all" 这类普通 English 词与短语，但数学家赋予这些词精确而无歧义的定义。

说来意外，正是在学习逻辑语言的过程中，我们会遇到计算机科学中最重要的未解问题——一个其解答可能改变世界的问题。

<span style="color:#1e8449;">**[译注]** 章首最后那句「最重要的未解问题」指的是 **$P$ vs $NP$**（（我的推论，非原书）依据是 §3.5 正式引入 SAT 时的原话），全书把它留到 §3.5 才正式登场；这里先埋一句，理由是要让读者知道自己即将学的东西不是修辞练习。**这条注只作坐标：读到 §3.5（SAT solvers）再回来读它。**

在 English 里，我们可以用 "not"、"and"、"or"、"implies"、"if-then" 这类词来修饰、组合、联系命题。例如，我们可以把三个命题组合成一个，像这样：

> **If** all humans are mortal **and** all Greeks are human, **then** all Greeks are mortal.
> （如果所有人都会死，并且所有希腊人都是人，那么所有希腊人都会死。）

接下来的好一阵子，我们不太关心命题**内部**长什么样——它们是关于数学还是关于希腊人的死——而关心命题如何被组合、被联系。所以我们经常用 $P$、$Q$ 这样的变量来代替具体命题，例如 "All humans are mortal" 与 "$2 + 3 = 5$"。这里的理解是：这些 propositional variable（命题变元）和命题一样，只能取 $\mathbf{T}$（true）与 $\mathbf{F}$（false）两个值。命题变元也叫 Boolean variable（布尔变元），得名于它们的发明者——十九世纪数学家 George Boole（你猜到了）。

#### 3.1.1 NOT, AND, and OR

数学家使用 NOT、AND、OR 这些词来表示「改变命题」与「组合命题」的运算。这些特殊词的精确数学含义可以用 truth table（真值表）来规定。例如，若 $P$ 是命题，则 "$\text{NOT}(P)$" 也是命题，而命题 "$\text{NOT}(P)$" 的真值由 $P$ 的真值按下表确定：

```math
\begin{array}{c|c}
P & \text{NOT}(P) \\ \hline
\mathbf{T} & \mathbf{F} \\
\mathbf{F} & \mathbf{T}
\end{array}
```

表的第一行说明：当命题 $P$ 为真时，命题 "$\text{NOT}(P)$" 为假。第二行说明：当 $P$ 为假时，"$\text{NOT}(P)$" 为真。这大概与你的预期一致。

一般说来，真值表给出的是：在变量的每一种可能真值组合下，命题的真/假取值。例如，命题 "$P \text{ AND } Q$" 的真值表有四行，因为两个变量共有四种真值设定：

```math
\begin{array}{cc|c}
P & Q & P \text{ AND } Q \\ \hline
\mathbf{T} & \mathbf{T} & \mathbf{T} \\
\mathbf{T} & \mathbf{F} & \mathbf{F} \\
\mathbf{F} & \mathbf{T} & \mathbf{F} \\
\mathbf{F} & \mathbf{F} & \mathbf{F}
\end{array}
```

> "If pigs fly, then you can understand the Chebyshev bound."
> （如果猪会飞，那么你能看懂 Chebyshev 界。）

> "If the moon shines white, then the moon is made of white cheddar."

**False Hypotheses**（假前提）

初学者得知「前提为假的蕴涵被视为真」时，往往感到不适。但前提为假的蕴涵在寻常场景里几乎不会出现，所以对逻辑学家与数学家给它的真值分配，大可不必介怀。

当然，数学约定「前提为假时蕴涵为真」是有充分理由的。一个有说明力的例子是 system specification（系统规格，见 Problem 3.12）：它由一系列规则组成，比方说十二条，

```math

```

```math
[C_1 \text{ IMPLIES } A_1] \text{ AND } [C_2 \text{ IMPLIES } A_2] \text{ AND } \cdots \text{ AND } [C_{12} \text{ IMPLIES } A_{12}]
```

**消失测试**：没有这条改写，SAT solver 与电路综合器就没法吃 implication——它们的内部表示只有 NAND/NOT（或 CNF 里的 clause），必须先把 $P \to Q$ 展成 $\neg P \vee Q$。而 (3.1) 那种「十二条规则之 AND」的规格会退化成 $12$ 个无法比较的原子公式，等价性检查得逐条手工做真值表，规模 $2^{12} = 4096$ 行。

**能直接算的最小例子**：取 $P = Q = \mathbf{F}$。$P \longrightarrow Q$ 为 $\mathbf{T}$（第 (ff) 行）；$\overline{P} \vee Q = \mathbf{T} \vee \mathbf{F} = \mathbf{T}$。再取 $P = \mathbf{T}, Q = \mathbf{F}$：前者 $\mathbf{F}$，后者 $\mathbf{F} \vee \mathbf{F} = \mathbf{F}$。两行都对上，而只有 $4$ 行要核。

**落点**：本节 §3.5（SAT）与 §3.4 的 DNF（p060）都建立在这个改写上；硬件侧对应德摩根律与 NAND 完备性，见 Problem 3.5/3.6。</span>

## p058 · 书内第 49 页（逆否 · 逆命题 · IFF 与两蕴涵之 AND）

页眉 `"mcs" — 2015/5/18 — 1:43 — page 49 — #57`；running head 为 `3.3. Equivalence and Validity`。

蕴涵 "$P \text{ IMPLIES } Q$" 的 contrapositive（逆否命题）。真值表表明：一个蕴涵与它的逆否命题等价——它们只是同一件事的不同说法。

相对地，"$P \text{ IMPLIES } Q$" 的 converse（逆命题）是陈述 "$Q \text{ IMPLIES } P$"。我们那个例子的逆命题是：

> If I am grumpy, then I am hungry.（如果我脾气差，那么我饿了。）

这听起来是个相当不同的主张，而真值表证实了这一怀疑：

```math
\begin{array}{cc|c|c}
P & Q & P \text{ IMPLIES } Q & Q \text{ IMPLIES } P \\ \hline
\mathbf{T} & \mathbf{T} & \mathbf{T} & \mathbf{T} \\
\mathbf{T} & \mathbf{F} & \mathbf{F} & \mathbf{T} \\
\mathbf{F} & \mathbf{T} & \mathbf{T} & \mathbf{F} \\
\mathbf{F} & \mathbf{F} & \mathbf{T} & \mathbf{T}
\end{array}
```

现在标出的两列在第二行与第三行不同，这就证实：一个蕴涵一般**不**等价于它的逆命题。

最后一个关系：一个蕴涵与它的逆命题合在一起，等价于一个 iff 陈述，具体地说，等价于「这两个陈述同时成立」。例如

> If I am grumpy then I am hungry, and if I am hungry then I am grumpy.
> （如果我脾气差那么我饿了，并且如果我饿了那么我脾气差。）

等价于单个陈述：

> I am grumpy iff I am hungry.（我脾气差当且仅当我饿了。）

我们再一次用真值表来验证这一点。

```math
\begin{array}{cc|c|c|c|c}
P & Q & (P \text{ IMPLIES } Q) & \text{AND} & (Q \text{ IMPLIES } P) & P \text{ IFF } Q \\ \hline
\mathbf{T} & \mathbf{T} & \mathbf{T} & \mathbf{T} & \mathbf{T} & \mathbf{T} \\
\mathbf{T} & \mathbf{F} & \mathbf{F} & \mathbf{F} & \mathbf{T} & \mathbf{F} \\
\mathbf{F} & \mathbf{T} & \mathbf{T} & \mathbf{F} & \mathbf{F} & \mathbf{F} \\
\mathbf{F} & \mathbf{F} & \mathbf{T} & \mathbf{T} & \mathbf{T} & \mathbf{T}
\end{array}
```

给出

```math
(P \text{ IMPLIES } Q) \text{ AND } (Q \text{ IMPLIES } P)
```

真值的那一列，与给出 $P \text{ IFF } Q$ 真值的那一列相同，这就证实了「两蕴涵之 AND」等价于 IFF 陈述。

## p059 · 书内第 50 页（§3.3.2 Validity and Satisfiability · §3.4 The Algebra of Propositions）

#### 3.3.2 Validity and Satisfiability（有效性与可满足性）

一个 valid（有效的）formula 是无论其变量取什么真值都**总是为真**的 formula。最简单的例子是

```math
P \text{ OR } \text{NOT}(P).
```

你可以把有效 formula 理解为捕获了根本的逻辑真理。例如，我们视为理所当然的一条蕴涵性质是：如果一个陈述蕴涵第二个陈述，第二个又蕴涵第三个，那么第一个蕴涵第三个。下面这个有效的 formula 证实了蕴涵的这条性质：

```math
[(P \text{ IMPLIES } Q) \text{ AND } (Q \text{ IMPLIES } R)] \text{ IMPLIES } (P \text{ IMPLIES } R).
```

formula 的等价性其实是有效性的一种特例。具体地说，陈述 $F$ 与 $G$ 等价，恰在陈述 $(F \text{ IFF } G)$ 有效之时。例如，表达式 (3.3) 与 (3.2) 的等价意味着

```math
(A \text{ OR } B) \text{ IFF } (A \text{ OR } (\text{NOT}(A) \text{ AND } B))
```

是有效的。当然，有效性也可以看作等价性的一面：一个 formula 有效，当且仅当它等价于 $\mathbf{T}$。

一个 satisfiable（可满足的）formula 是**有时候**能为真的 formula——也就是说，存在对它各变量的一种真值指派使它为真。可满足性出现的一个场合，是手里有一组 system specification（系统规格）的时候。系统设计者的工作就是拿出一个遵守所有规格的系统。这意味着：所有规格的 AND 必须是可满足的，否则设计者的任务就是不可能的（见 Problem 3.12）。

有效性与可满足性之间也有紧密关系：陈述 $P$ 可满足，当且仅当它的否定 $\text{NOT}(P)$ 不是有效的。

### 3.4 The Algebra of Propositions（命题代数）

#### 3.4.1 Propositions in Normal Form（命题的标准形式）

每个命题公式都等价于某个 "sum-of-products"（和之积，即积之和）形式，也叫 disjunctive form（析取形式）。更精确地说，析取形式就是一个由 AND-term 组成的 OR，其中每个 AND-term 是若干变量或其否定的 AND，例如

```math
(A \text{ AND } B) \text{ OR } (A \text{ AND } C).
```

（原书编号 (3.4)。）

<span style="color:#1e8449;">**[译注]** 那句「所有规格的 AND 必须可满足，否则设计者的任务是**不可能**的」就是 SAT 问题的原始形态，也是本章章首那个「最重要的未解问题」的落点：给一堆布尔约束，问是否存在一组真值指派同时满足全部。注意它与有效性是**同一个判定的两面**：$F$ 可满足 $\iff$ $\text{NOT}(F)$ 不有效。

**消失测试**：没有「可满足性」这个判准，规格冲突只能靠人肉枚举：$n$ 个布尔量有 $2^n$ 行真值表，$n = 30$ 时约 $1.07 \times 10^{9}$ 行，$n = 50$ 时约 $1.13 \times 10^{15}$ 行——后者在一台每秒 $10^{9}$ 行的机器上要跑 13 天。真实硬件的配置空间（$n$ 上到 $10^3$–$10^5$）连枚举这条路都没有。

**能直接算的最小冲突例子**：取两条规格 $C = \{P, \text{NOT}(P)\}$。$P \wedge \neg P$ 的真值表两行都是 $\mathbf{F}$，可满足性判定给出 UNSAT，于是「设计者任务不可能」这句话就成了定理而不是抱怨；若人工检查只看单条规格，会觉得两条各自都完全合理。

**落点**：§3.5 SAT solvers（下一页起）、Problem 3.12（spec 冲突）；Q3 承重点：EDA 里的 logic equivalence checking、bounded model checking、SMT 求解器（Z3）都是这一句的工程实现。</span>
