## 整理说明

- **命名修正**：原 `附录_Bibliography_参考文献.pdf` 实为**教材英文原书全本（920 页）**，已移入 `教材/` 并改正文件名。
- **扫描件**：原为逐页手机扫描（同一页常被重复扫描、且顺序与书页不符），处理方式为 ① 感知哈希去重 → ② OCR 提取页眉页码 → ③ 按页码重排 → ④ 合并为整册。结果：53 页 → **33 页**，覆盖第 18 章正文页码 **p.739–765**。
- **章节结构索引**：`I_*` / `III_*` / `IV_*` / `附录_*` 下的数百个 Word 文档仅为「章 → 节 → 小节」的标题占位（无正文），已额外导出为 `章节结构索引.md` 一份层级清单，便于检索。
